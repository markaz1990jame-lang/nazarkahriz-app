# مرکز جامع نظرکهریز 🦁

اپلیکیشن تمرین و توان‌بخشی مهارت‌های نوشتاری فارسی برای دانش‌آموزان **پایه اول تا سوم ابتدایی** — قابل نصب روی گوشی اندرویدی و کارکرد کامل **بدون اینترنت**.

## 📲 دانلود و نصب APK روی گوشی اندرویدی

1. روی گوشی، فایل APK آخرین نسخه را دانلود کن:
   **[دانلود Nazarkahriz.apk از Releases](../../releases/latest/download/Nazarkahriz.apk)**
2. بعد از دانلود، روی فایل بزن؛ اندروید پیام «نصب برنامه‌های ناشناس» می‌دهد → اجازه بده (برای Chrome: تنظیمات ← نصب برنامه‌های ناشناس ← اجازه).
3. «نصب» را بزن. آیکون شیر نظرکهریز روی صفحه اصلی ظاهر می‌شود. 🎉
4. داده‌ها فقط روی خود دستگاه ذخیره می‌شوند؛ برای انتقال بین گوشی‌ها از «پشتیبان‌گیری» داخل اپ استفاده کن.

> نسخه APK از نوع Debug است و برای آزمایش مرکز مناسب است. حداقل اندروید موردنیاز: ۶ (API 23).

## 🧩 قابلیت‌ها

- پرونده مستقل برای هر کودک (پایه اول تا سوم)
- سه مهارت: دنبال‌کردن مسیر، شکل‌دهی حروف فارسی، نوشتن مستقل
- موتور تطبیقی قواعدمحور (آستانه ۸۵٪ / ۶۰٪) با نظارت و تأیید متخصص
- ثبت دقت، زمان، خروج از مسیر و میزان راهنما برای هر تلاش
- گزارش نموداری برای متخصص + ویرایش برنامه تمرینی
- پاداش (ستاره و نشان) و راهنمای صوتی فارسی
- پشتیبان‌گیری رمزگذاری‌شده (AES-GCM) برای انتقال پرونده بین خانه و مرکز
- کارکرد کامل آفلاین — داده‌ها فقط روی دستگاه (حفظ حریم خصوصی کودک)

## 🛠 ساخت APK از سورس

ساخت خودکار با GitHub Actions انجام می‌شود (`.github/workflows/build-apk.yml`):

```bash
bun install            # نصب وابستگی‌ها
bun run build:static   # خروجی استاتیک Next.js در out/
bunx cap add android   # افزودن پلتفرم اندروید (Capacitor)
bunx @capacitor/assets generate
cd android && ./gradlew assembleDebug
```

خروجی: `android/app/build/outputs/apk/debug/app-debug.apk`

## 🌐 نسخه وب (PWA)

همین سورس یک PWA هم هست: با `bun run dev` اجرا کن و در Chrome اندروید «افزودن به صفحه اصلی» بزن.

## ⚠️ محدودیت‌ها (مطابق سند نیازمندی نسخه ۱.۰)

- این نرم‌افزار ابزار **تمرین و پایش عملکرد لمسی** است، نه ابزار تشخیص قطعی اختلال یادگیری.
- درصدهای دقت، «دقت در تمرین لمسی» هستند و معیار نوشتن با مداد روی کاغذ نیستند.
